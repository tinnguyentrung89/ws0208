🚀 Setup Guide
Setup 1 lần (~10 phút) để có app native trên iPhone + tự động mở đúng giờ học.
📦 BƯỚC 1: Deploy file lên Netlify (5 phút)
1. Trên máy tính, mở app.netlify.com/drop
2. Kéo file IT_English_Master.html vào ô màu xanh
3. Đợi 5-10 giây → có URL như https://abc-xyz.netlify.app
4. Tap "Claim your site" → đăng ký free (giữ vĩnh viễn)
5. Copy URL — dùng cho bước sau
📱 BƯỚC 2: Add to Home Screen (30 giây)
1. Mở Safari trên iPhone (KHÔNG dùng Chrome)
2. Paste URL Netlify vào → app mở
3. Tap nút Share (ô vuông + mũi tên dưới màn hình)
4. Cuộn xuống → tap "Add to Home Screen"
5. Đặt tên "IT English" → Add
✅ Icon xuất hiện trên Home Screen như native app
🤖 BƯỚC 3: Setup Shortcuts Auto-open (3 phút)
Mở app Shortcuts trên iPhone → tab Automation

Tạo 3 automations giống nhau (8:00 / 12:30 / 21:00):
1. Tap + → Create Personal Automation
2. Chọn Time of Day
3. Set giờ + Daily + ✅ Run Immediately
4. Next → Add Action → search "Open URL"
5. Paste URL Netlify → Done

✅ Đúng giờ là banner hiện → tap 1 phát mở app
💾 BƯỚC 4: Save URL vào Reminders
1. Mở app Reminders → tìm 3 reminders "IT English"
2. Mở từng cái → tap vào note
3. Paste URL Netlify vào đầu note
4. iPhone sẽ auto-detect URL thành link tap được
✅ Khi reminder kêu → tap URL → mở app
